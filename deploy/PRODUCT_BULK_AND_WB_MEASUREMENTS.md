# Массовые статусы и измерения WB

В `/admin/products/` отметьте товары или используйте «Выбрать все товары в списке».
Выберите статус и нажмите «Применить к выбранным». Лимит — 500 товаров.
Выбор всех применяется только к текущему результату поиска и доступным для редактирования строкам.

Публикация требует `products.publish` и видимой категории. Для импортированных
товаров без категории можно выбрать её в панели массового действия. Существующие
видимые категории сохраняются; скрытая основная категория заменяется видимой.
При любой ошибке весь пакет отменяется. Синхронизация и массовая запись защищены
общей блокировкой; каждый изменённый товар фиксируется в журнале аудита.
Статус публикации не меняет цену, остаток, изготовление под заказ, фото и группировку.
Товар с нулевым остатком виден, но не заказывается без изготовления под заказ.

Импорт WB сохраняет `dimensions` карточки как упаковку (см → мм, кг → г).
Поля самого изделия читаются из `characteristics`; единицы берутся из
`/content/v2/object/charcs/{subjectID}` и кешируются в памяти на время запуска.
Нетто и брутто не смешиваются. Неполные/невалидные упаковки, неизвестные единицы,
диапазоны и противоречивые значения не угадываются. Длина кабеля не считается
длиной изделия; диаметр остаётся именованной характеристикой с единицами.
Пустой ответ API не стирает уже заполненные измерения. В режиме SITE сохраняются
ручные значения; импорт заполняет только пустые поля, а упаковку — только если
все четыре её поля пусты.

После обновления повторите синхронизацию WB в ЛК → Маркетплейсы.
Деплой сам по себе не запускает импорт и не публикует товары.
