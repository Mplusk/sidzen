# GitHub migration archive

`pull-requests.json` preserves the source repository's pull-request titles,
descriptions, authors, dates, status, and Git references. Its comments and
reviews were empty when exported. These records are an archive: the original
GitHub pull-request pages will no longer work if the source repository is
deleted. Original commit history and branches are preserved in Git.

The Ozon delivery fix that was open at migration time remains available in the
`fix/ozon-quote-transient-rejections` branch.
