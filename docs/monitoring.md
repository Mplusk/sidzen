# Мониторинг SIDZEN

Раздел `/account/monitoring/` доступен только с `monitoring.read`; очистка требует `monitoring.clear` и отдельного подтверждения. Эти права по умолчанию есть только у admin/superadmin. Очистка не касается заказов, клиентов и диагностического журнала; в аудите остаётся только количество удалённых визитов.

Сбор включается отдельным добровольным согласием. Прежняя кнопка «Понятно» не считается согласием. Подписанная HttpOnly cookie и серверная запись согласия действуют 30 дней. После отказа запись согласия и визиты браузера удаляются. Повтор старой cookie не восстанавливает данные. DNT/GPC учитываются. После общей очистки согласие запрашивается заново.

Записываются только разрешённые публичные маршруты. Формы, произвольные query-параметры, email, телефоны, ключи доступа и закрытые маршруты исключены. Источник — только внешний домен; фраза — только безопасный параметр известного поисковика, если он передан. Браузер не идентифицирует человека: смена браузера/cookies даёт новую идентичность. Администраторы и распознанные боты не учитываются. Время оценивается по heartbeat каждые 30 секунд; скрытая вкладка и простой дольше минуты не учитываются. Визит разделяется после 30 минут бездействия; несколько вкладок могут учитываться отдельно.

IP берётся только из `X-Sidzen-Client-IP`, который Caddy всегда перезаписывает реальным адресом соединения. Порт приложения не должен быть открыт наружу. Для стороннего CDN потребуется отдельная проверенная конфигурация доверенных прокси; нельзя доверять произвольному X-Forwarded-For.

Страна определяется локально, без внешних запросов, по пакетным бинарным файлам `@iplookup/country@1.0.20261010`. Исполняемый код пакета НЕ импортируется: он обращается к CDN. Данные user-country: https://github.com/sapics/ip-location-db ; пакет заявляет CDLA-Permissive-2.0 для данных, MIT для кода (https://github.com/sapics/ip-location-api). Страна приблизительна; база обновляется при обновлении закреплённой зависимости, не автоматически в runtime. В standalone входят только серверные файлы данных.

Worker каждый час удаляет визиты и согласия старше 30 дней. Чистятся также дочерние страницы. Нормальный максимум: 20 000 визитов, 100 000 просмотров, 30 000 согласий, 200 страниц на визит; превышение останавливает сбор, но не магазин. Очистка и события сериализованы advisory lock; heartbeat не создаёт отсутствующую страницу. API ограничивает тело 4 КБ, частоту запросов и проверяет Origin. Сырые запросы/ошибки в общий журнал не пишутся.

Действующая БД и резервные копии должны размещаться в РФ. Оператору перед включением следует проверить, что уведомление/документы об обработке охватывают добровольную статистику, определить доступ сотрудников и срок резервных копий. Удаление из действующей БД не удаляет автоматически старые резервные копии.
