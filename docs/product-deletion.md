# Полное удаление товара

В ЛК администратора: Товары → Удалить (либо редактирование товара → Удаление товара). Действие требует подтверждения. Нужны products.write, а для опубликованного товара — также products.publish.

Транзакция удаляет товар, варианты, категории-связи, отзывы и их фото, избранное, позиции в корзинах, задания AI и привязки маркетплейсов. Общие справочники и другие товары группы не удаляются. Снимки состава старых заказов сохраняются; доставка заказов не отменяется. Неиспользуемые загруженные изображения удаляются, общие изображения сохраняются. Аудит действия остаётся.

Удаление происходит только на сайте, не в WB/Ozon. По запросу владельца следующая ручная синхронизация снова импортирует отсутствующий товар как новую карточку (обычные правила сопоставления SKU/штрихкодов, новый ID, статус черновик, прежние отзывы не восстанавливаются). Пока синхронизация выполняется или ожидает запуска, удаление запрещено.

Проверки: `pnpm test`; `SMOKE_BASE_URL=http://localhost:3101 pnpm exec tsx scripts/smoke-product-delete-http.ts` с локальной базой shop_qa. HTTP-проверка отказывается работать на внешнем сервере/базе и удаляет только созданные ею тестовые записи.
